## 🌱 What is AlgoBloom?

AlgoBloom is a growing collection of **Data Structures and Algorithms implemented in C**, designed to make learning more understandable, practical and interesting.

Here, we don't just write code and celebrate when it compiles.

We ask questions.

We understand the logic.

We trace what happens inside the program.

We examine mistakes.

And finally, we explore whether our solution can become more efficient.

Because honestly...

**A program that works is good. Understanding WHY it works is even better.** 🧠

## 🧭 Our Learning Journey

Every topic follows a simple learning journey:

| Stage | What happens? |
|---|---|
| 🌱 Learn | First, let's understand what this concept actually means. |
| 🧠 Understand | Explore the logic, algorithm and working process. |
| ✍️ Design | Develop pseudocode before jumping into C. |
| 💻 Implement | Finally, convert our logic into working code. |
| 🔍 Investigate | Dry-run the program, test edge cases and find mistakes. |
| ⚡ Optimise | Analyse complexity and explore better approaches. |
| 🎬 Visualise | Watch the algorithm work through demonstrations. |

No magical jumps from problem statement to 50 lines of code. Promise. 🤝

## ⚡ Let's Talk About Efficiency!

So, your program works. Congratulations! 🎉

But wait...

What happens when the input size becomes 1,000? 10,000? 1,00,000?

Will your algorithm still perform efficiently?

That's where complexity analysis enters the picture.

We'll explore:

- Best-case time complexity.
- Average-case time complexity.
- Worst-case time complexity.
- Auxiliary space complexity.

We'll also compare different approaches to understand why one algorithm may be more suitable than another.

Because writing working code is one skill.

**Writing efficient code requires understanding what happens as the problem grows.** ⚡
