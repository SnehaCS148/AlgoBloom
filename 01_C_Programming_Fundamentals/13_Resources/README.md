# 🧠 HOW TO USE THIS LIBRARY

<details>
<summary>🌱 I'm a beginner. Where should I start?</summary>

Start with:

1. C Quick Reference.
2. Basic C program template.
3. Structure of a C program.
4. Input/output visual notes.

Then follow the chapter lessons in sequence.

</details>

<details>
<summary>😵 I need to revise quickly. What should I open?</summary>

Start with the Cheat Sheets and Quick Reference collections.

Use them alongside the corresponding chapter lessons.

</details>

<details>
<summary>🐛 My program isn't working. Help!</summary>

Visit Compilation & Debugging.

First identify whether your problem is:

- Syntax error
- Compilation error
- Runtime error
- Logical error

Then investigate the cause instead of randomly changing code. 🧐

</details>
